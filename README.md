# 大学化学实验学习平台（昆明理工大学理学院 · 公开预览站）

面向昆明理工大学理学院《无机化学实验》《分析化学实验》课程的**课前预习材料**：
2 本教材、10 个实验、40 张预习卡（每个实验 4 张）。本站在线公开、只能阅读，
教学以指导教师现场要求与实验室安全规程为准。

> 定位：**公开预览版**（public preview / 公开资料站）。不是课程生产系统，不做登录、
> 不采集学习数据、不承诺跨设备同步进度，也不作为考核或成绩依据。

## 一、在线地址

- 平台首页：<https://zzqlittlebean.github.io/Chemistry_Safety_Preview_Platform_KUST/>
- 已印制在预习材料 PDF 上的二维码指向 6 个无机化学实验深链：
  `#exp/inorganic/e01` ～ `#exp/inorganic/e06`（路由同时兼容 `#/exp/...`）。

  手机端图片较多，建议在 Wi-Fi 下先打开一次，之后由浏览器缓存。

## 二、使用说明

1. 首页 → 选择教材（无机化学实验 / 分析化学实验）→ 选择实验；
2. 每个实验含 4 页预习内容：**安全教育 → 实验目的 → 实验流程 → 实验思考**，
   每页底部还有“预设问答”（根据本实验材料整理的常见问题，暂未接入大模型）；
3. 阅读进度只保存在**本机浏览器的 localStorage**：换设备、换浏览器、清理缓存都会丢失，
   也不作为考核依据；如果页面显示“已读/完成”，只代表本机曾打开过对应页面；
4. 无登录、无账号、无后端接口，页面不上传阅读记录；姓名输入框可选，仅用于在本机
   生成“学习状态分享图”，详见“隐私与免责”；
5. “关于”页汇总了版本、内容来源与版权、免责声明和纠错联系方式。

## 三、隐私与免责

- **不收集学习数据**：本站不使用 cookie，不接入统计、广告或埋点脚本；所有内容为静态文件，
  没有自建后端。GitHub Pages 平台本身会按 GitHub 的隐私政策记录访问日志，本站无法访问该日志。
- **姓名可选、只存本机**：完成实验时可自愿填写姓名，仅用于在浏览器里绘制“学习状态分享图”
  并保存到本机；姓名只写入本机 localStorage，不上传、不进入服务器；不填姓名不影响使用。
- **进度只在本机**：阅读进度、完成状态均保存在本机 localStorage；换设备、清缓存即丢失，
  任何人无法从本站获得你的学习记录。
- **第三方工具提示**：部分实验的“实验流程”页含指向第三方在线工具（托管在 dkfile.net 等平台，
  如产率计算器、晶体质量评价系统、溶度积计算器、HAc 解离常数计算器）的二维码或链接。
  这些页面不是本站提供、不受本站控制，可能随时变更或失效；请勿在第三方页面输入姓名、学号、
  照片等个人信息，也不要上传可辨识人脸或校服的照片。使用第三方工具的风险由使用者自行承担。
- **化学实验风险**：本材料仅用于课前预习。化学实验有风险，所有操作必须按指导教师现场要求、
  实验室安全规程与学校相关规定执行；预习材料可能因教材版本、设备差异而表述不全，
  不构成操作依据。
- **内容纠错**：如发现版权、事实或图片问题，请在仓库提交 Issue（见文末），我们会核实处理。

## 六、数据格式（给二次开发者）

页面数据为 `window.__CHEMLAB__ = { site, books, exps }`：

- `site`：站点名称、单位、版本、更新说明、公告、教材清单、版权/来源/免责/联系文本；
- `books[教材 id]`：教材名称、封面、排序、安全海报、实验清单；
- `exps[教材 id + "/" + 实验 id]`：实验名称、4 张卡（`cards`）与预设问答（`qa`）。

内容块（block）类型：`h`（标题）、`p`（段落）、`kv`（键值）、`img`（图片）、
`fig`（带图注图片）、`table`（表格）。富文本只允许少量受控标签，页面渲染前会做白名单净化。

派生字段在**构建期**重算：

- `cards[].count` = 该卡中非标题块的数量；
- `book.json experiments[].points` = 该实验所有卡的 count 之和；
- `site.json textbooks[].total` = 该教材的实验数。

可见性字段（重要）：

- `visibleAt` 是**开放时间**：未到开放时间的教材/实验，页面会显示“尚未开放”并拦截入口；
  但全部内容已打包进 `bundle.js`，直接读取数据文件即可获得全文，因此它只是展示排期，**不是访问控制**；
- `hidden` 只是**从列表隐藏**，直链仍可访问，同样不是访问控制。

## 七、如何更新内容

1. 修改 `data/site.json`、`data/textbooks/<教材>/book.json` 或
   `data/textbooks/<教材>/exps/<实验>/exp.json`；
2. 用课程组内部的构建脚本重新生成 `data/bundle.js`，并重算上述派生字段（total / points / count）；
3. 把新图片放入 `assets/exps/<实验>/`，同步更新 JSON 中的 `src`（扩展名可能是 .png/.jpg/.jpeg）
   以及图片的 `alt`、`w`、`h`；
4. 跑一致性校验：bundle 与源 JSON 逐字段一致、派生字段正确、所有图片引用都存在且非 0 字节；
5. 提交并推送，GitHub Pages 会在 1～2 分钟内重建。

仓库内没有编辑器与构建脚本，需要更新内容请联系课程组（或提交 Issue）。
